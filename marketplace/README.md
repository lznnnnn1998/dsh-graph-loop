# Marketplace metadata

Listing entries for the [awesome-dsh-plugin](https://github.com/awesome-dsh-plugin/awesome-dsh-plugin)
marketplace, one per published package:

- `lznnnnn1998__dsh-graph-loop--packages-loop.yml` — the driver (`packages/loop`)
- `lznnnnn1998__dsh-graph-loop--packages-graph-ui.yml` — the Graph tab (`packages/graph-ui`)
- `lznnnnn1998__dsh-graph-loop--packages-mode.yml` — Explore mode (`packages/mode`)

Each file is source metadata for a marketplace submission: a repository URL, a package name, a
category and an English/Chinese description. They are not npm package files and are not installed by
DSH. Package names and release steps live in [`docs/PUBLISHING.md`](../docs/PUBLISHING.md); the
installed behavior of each bundle is documented in its package README.
