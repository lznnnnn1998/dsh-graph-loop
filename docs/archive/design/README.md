# design/ — archived pre-implementation contracts

These files were the 0.1 design drafts (`design/*.ts`, `example-graph.yaml`,
`measurements.md`). They are **not** compiled or imported by the live packages:
`tsconfig.json` covers only `packages/**` and `test/**`.

They were moved here in the 0.2 audit cleanup (P0-3) because the live
implementation lives in `packages/core/src/`. The two documents cited as
evidence — `measurements.md` and `example-graph.yaml` — are kept; the `.ts`
drafts are kept only as history. `research/*.md` references to `design/…` mean
this directory.

Superseded by: `packages/core/src/` (the live implementation).
